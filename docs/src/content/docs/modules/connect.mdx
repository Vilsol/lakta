`pkg/http/connect` runs a Connect-RPC server as a `SyncModule`. One `net/http` handler serves Connect, gRPC-Web, and gRPC on a single port — cleartext HTTP/2 (h2c) lets gRPC clients connect without TLS.

## Setup

Register services with `WithService`. The registrar runs during `Init` (when the injector is in context) and receives the shared interceptor chain to pass into the Connect constructor.

```go compile=skip
lakta.NewRuntime(
    config.NewModule(
        config.WithConfigDirs(".", "./config"),
        config.WithArgs(os.Args[1:]),
    ),
    tint.NewModule(),
    slog.NewModule(),
    otel.NewModule(),
    connect.NewModule(
        connect.WithService(func(ctx context.Context, opts []connectrpc.HandlerOption) (string, http.Handler) {
            return greetv1connect.NewGreetServiceHandler(NewServer(), opts...)
        }),
    ),
)
```

## Registering services

`WithService` is the recommended path: it defers handler construction to `Init` so you can resolve dependencies with `lakta.Invoke[T](ctx)`, and it injects the built-in interceptor chain into your handler.

For a pre-built handler that already carries its own options, use `WithHandler(path, handler)`. Note the shared interceptor chain is **not** applied to handlers registered this way — the handler is mounted as-is.

## Interceptors

The interceptor chain is a fixed sequence of named slots (outer to inner). Every slot wraps unary and streaming handlers:

| Slot | Default |
|---|---|
| `SlotOtel` | otelconnect tracing and metrics; remote span contexts are trusted |
| `SlotRequestID` | accepts an inbound `X-Request-Id` only if it is a UUID or ULID, otherwise generates a ULID; puts it in ctx (`RequestID(ctx)`), the ctx logger and the response |
| `SlotAccessLog` | one log line per finished call with procedure, code and duration |
| `SlotErrorBoundary` | renders, logs and records every error from the slots below (see below) |
| `SlotRecovery` | turns a handler panic into an error with the panic stack |
| `SlotDeadline` | applies `default_deadline` to unary calls without one and caps them at `max_deadline` |
| `SlotAuth`, `SlotAuthz` | empty; filled by auth modules or the application |
| `SlotValidate` | protovalidate on every request message |
| `SlotUser` | empty; `WithInterceptors(...)` appends after it |

Replace or fill a slot with `WithSlot(slot, factory)`. Factories run during `Init`, so they can resolve DI dependencies. Security interceptors must implement `WrapStreamingHandler` as well as `WrapUnary`.

### Error boundary

Every failed call is handled once, at the boundary:

- **Wire:** the error is mapped through `pkg/errors.FromError`. For oops errors, an `errors.Class*` tag selects the status, `Code()` becomes `ErrorInfo.Reason`, `In()` becomes `ErrorInfo.Domain`, and `Public()` is the only text the client sees. oops context, stack and cause never reach the wire.
- **Log:** one line with the full error (oops context and stack included), at `ERROR` for 5xx classes and `WARN` otherwise.
- **Trace:** `span.RecordError` with `error.code` and `error.domain`; the span status is set to error for 5xx classes only.

```go
var errNoteNotFound = oops.In("note").Code("NOTE_NOT_FOUND").Tags(errors.ClassNotFound).Public("note not found")
```

### Limits

Before connect reads the request body, an HTTP middleware refuses `GET` to procedures unless `allow_get` is set, and for unary procedures caps the body at `read_max_bytes` and applies `read_timeout`. Streams are capped per message by `read_max_bytes` only. `WithHTTPMiddleware` adds your own middleware around the whole handler.

### Mounted services

`WithMountedHook` receives the descriptors of every mounted protobuf service at the end of `Init` (for example to check that every RPC carries an authorization rule). A hook error fails `Init`.

## Transport security

By default the server listens in plaintext with h2c enabled (`WithH2C`), so gRPC clients connect without TLS. Configure file-path based TLS to serve HTTP/2-over-TLS instead — when TLS is set, h2c is ignored.

## Multi-instance

```go compile=skip
connect.NewModule(
    connect.WithName("internal"),
    connect.WithService(internalRegistrar),
),
connect.NewModule(
    connect.WithName("public"),
    connect.WithPort(9090),
    connect.WithService(publicRegistrar),
),
```
