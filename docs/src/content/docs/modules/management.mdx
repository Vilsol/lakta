`pkg/http/management` serves operational endpoints on their own port (default `8081`), apart from the API server:

| Path | Purpose |
|---|---|
| `/health` | Liveness: `200` while the process serves. Never checks dependencies, so a downstream outage does not restart pods. |
| `/ready` | Readiness: runs every check registered on `*health.Health` (from `pkg/health`) at request time; `503` when a required check fails. Checks registered after `Init` (lazy clients) are included. |
| `/metrics` | Prometheus exposition of the private registry the `otel` module provides. |

## Setup

```go
lakta.NewRuntime(
	config.NewModule(),
	otel.NewModule(),
	health.NewModule(),
	management.NewModule(),
	// ...
)
```
